# real-estate-landing-page
# 🏠 Real Estate Landing Page

A modern, responsive real estate landing page built with **HTML, CSS, and JavaScript**.

This project is designed for real estate agencies to showcase properties, attract potential buyers, and make property viewing requests easier.

## ✨ Features

- 📱 Fully Responsive Design
- 🏠 Modern Real Estate UI
- 🔎 Property Search
- 🏘️ Featured Properties Section
- ⭐ Client Testimonials
- 📊 Agency Statistics
- 📞 Contact & Property Viewing Form
- 💬 WhatsApp Contact Button
- 📱 Responsive Mobile Navigation
- ✨ Smooth Scroll Animations
- 🎨 Hover Effects
- 🖼️ Property Image Gallery

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
